# Coach Timer — Chronomètre de cours collectif (Android APK)

Application Android gratuite et hors-ligne pour coachs sportifs (HIIT, Tabata, Circuits, EMOM, Séries & Cycles illimités).

## Obtenir le fichier Coach-Timer.apk gratuitement via GitHub
1. Envoie ce dossier sur un nouveau dépôt GitHub nommé `coach-timer`.
2. Sur GitHub, ouvre l'onglet **Actions** → clique sur **Construire Coach Timer APK**.
3. Patiente ~3 minutes jusqu'à la coche verte.
4. En bas de la page, clique sur **Coach-Timer-APK** pour télécharger l'archive contenant `Coach-Timer.apk`.
5. Transfère `Coach-Timer.apk` sur ton téléphone Android et touche-le pour l'installer (autorise « Installer des applications inconnues » si demandé).

## Tester sur Mac en local
```bash
npm install
npm run dev
```
